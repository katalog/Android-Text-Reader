# 추가 아이디어 (백로그)

기본 기능 구현은 완료됨. 아래는 이후에 추가로 고려 중인 항목들.

- 폴더 싱크 동작 이상함. 
    apk - 서버 간 싱크할때 연결 된 이후 apk 쪽에서 파일 다 받음. 그 이후에 서버쪽에서 파일 위치 변경(./d 폴더 ./c/d 로 옮기는 등) or
    폴더+파일 삭제, 빈 폴더 생성 등 했더니 apk 쪽에선 에러 남. 확인 필요

- 공식 프로젝트 문카타 리더 만들고 그 공식 프로젝트에 링크로 apk, vscode, go서버 연결        

- TTS 기능 자체가 지금 설정만 있고 TTS가 되게 하는 기능이 없는거 같은데 이거 확인

- 챕터 건너뛰기 기능이 챕터패턴이 너무 가까운 경우 그냥 건너뛰게. 꼭 이렇게 연결되지 않더라도 챕터패턴 이후에 한 10줄? 20줄 안에 또 챕터패턴 있으면 그건 나누기 점프 하지말고 챕터패턴 에서 챕터패턴으로 바로 가게
    예제문장: 
    ## 추신: 오늘은 1회만 연재합니다. 내일은 3회 연재가 있을 예정입니다. 이 에피소드는 아마 내일이면 끝날 것입니다.

    ## 제134장. 주화입마, 전투력 배가

    봉의루 꼭대기, 5층 화청(花廳) 안.

- **로컬 LLM 기반 TTS**: 기존 Android `TextToSpeech` 대신 로컬에서 돌아가는 LLM(음성합성 모델)을 사용해 더 자연스러운 한국어 발음 제공. 모델 파일을 한 곳이 아니라 여러 소스에서 받을 수 있게 지원 (다운로드 소스 다중화).
